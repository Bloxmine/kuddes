# Kuddes: tech stack

How Kuddes is built, for anyone who wants to work on the code. To run it or
set up your own server, see [README.md](README.md) and [DEPLOY.md](DEPLOY.md).
How servers talk to each other is in [WEIDE.md](WEIDE.md).

## Stack

| Part | What |
| --- | --- |
| Frontend | React 19 + TypeScript, built with Vite. React Router for pages, TanStack Query for data. Plain CSS next to each component, with no CSS framework. |
| API | Node (24 LTS) with Hono. The same process serves the built app in production. |
| Database | PostgreSQL 17, run in Docker. Drizzle ORM for the schema and queries, drizzle-kit for migrations. |
| Validation | zod v4, on the server; the limits are shared with the frontend through `shared/`. |
| Images | sharp: every upload is re-encoded to WebP, with metadata stripped. |
| Video, music, radio | ffmpeg (installed on the server). |
| Real-time | Server-sent events for notifications, chat and the timeline. WebRTC for Messenger calls and games, peer to peer. |
| Mail | nodemailer over SMTP (any mail service). |
| Federation | ActivityPub with Weide's extensions: HTTP Signatures, WebFinger and NodeInfo. A queue in Postgres delivers to other servers. |
| Tooling | TypeScript 6, oxlint, tsx (runs the server without a build step). |
| Production | Caddy (HTTPS and reverse proxy), systemd, nightly `pg_dump` backups (see `deploy/`). |

Sessions are random tokens in an httpOnly cookie. The database keeps only
their SHA-256. Passwords are hashed with scrypt.

## Structure

```text
server/                Hono API
  index.ts             middleware (CSP, rate limits, sessions, consent and waitlist gates) and the routes
  db/                  Drizzle schema (schema.ts), migrations, migrate script
  routes/              one file per area: auth, users, statuses, knuffels, photos, kuddes, forum, federation…
  lib/                 sessions, uploads, notifications, moderation, bots, automations, reports…
    federation/        Weide/ActivityPub: actors, signatures (http.ts), inbox, outbox, delivery queue, server policies
  scripts/admin.ts     grant or revoke the admin role, approve members, reset passwords (npm run admin)
shared/                types, limits and constants used by both the server and the app
src/
  components/          layout (header, footer, menus), ui (Box, Button, FarmIcon…), social, catalog pages
  features/            one folder per feature (profile, timeline, forum, messenger, studio, federation…)
  pages/               one component per route
  lib/                 API client, auth, query hooks, formatting
  styles/              global CSS, theme variables, mobile rules
public/                icons, fonts, smileys, textures and other static files
games/bejeweled/       an HTML5 port of Bejeweled 3; its art comes from the game itself (see its README)
deploy/                Caddyfile, systemd units, production .env example, backup and update scripts
tools/                 scripts that made some of the art and texture lists
```

## Conventions

- **Language:** UI text is Dutch. Code, comments and commit messages are
  English. Comments say why, in plain words.
- **Shared code:** anything both sides need (types, limits, categories) goes
  in `shared/`.
- **Icons:** Farm-Fresh PNGs through `<FarmIcon name=…>`. Smileys use
  `<Smiley>`. No emoji or other icon sets in the interface.
- **Colours:** they come from CSS variables (`--brand`, `--tint-1`,
  `--box-border`…), so themes and profile designs work. Never hardcode a
  theme colour.
- **List pages** reuse `src/components/catalog/`.
- **Notifications** go through `notify` and `notifyMentions` in
  `server/lib/notifications.ts`, and `unnotify` when the thing is deleted.
- **Federation:** an action that should reach other servers calls a function
  in `server/lib/federation/outbox.ts`. Those functions never throw into the
  request that called them.

## Database and migrations

- **Schema:** it lives in `server/db/schema.ts`.
- **Changing it:** edit the schema, then run `npm run db:generate` (makes a
  migration in `server/db/migrations/`) and `npm run db:migrate`.
- **Servers:** they run their migrations on every update (`deploy/update.sh`).

## Checks

```sh
npx tsc -p tsconfig.app.json --noEmit && npx tsc -p tsconfig.server.json --noEmit
npm run lint
npm run build
```

## Features in detail

- **Accounts:** sign up and log in with username or e-mail. Passwords are hashed with scrypt; sessions use httpOnly cookies. Members can change their password and delete their account (everything they posted is deleted with it).
- **Profiles:** "Wie ben ik?" at the top or bottom of the Profiel box, as you choose under it in Instellingen → Over jou (`preferences.aboutFirst`); the Knuffels tab loads 20 at a time with "Meer knuffels bekijken"; a WieWatWaars tab with all of them (15 at a time, "Oudere laden"), and on the Over tab the WieWatWaar box with the latest one, "Eerdere bekijken" for the few before it and "Alle" to the tab; details, "Wie ben ik?", brands, spots and music. Profile photo, profile views, respect, and "Laatste bezoekers" (only visible to the profile owner). Members can pick a profile skin ("pimp je profiel").
- **Tijdlijn ("Overzicht", `/tijdlijn`):** four views (Normaal, Compact, Raster with the cards fitted together by `src/lib/masonry.ts`, Lijst with one line per item that opens in place), remembered per browser. everything members do (WieWatWaars, photos, knuffels, new friendships, profile photos, joining Kuddes), filterable by tab, with respect and reactions on every item and online friends alongside. Activities are recorded in the `activities` table as they happen.
- **WieWatWaar:** status updates with light formatting (`**vet**`, `*schuin*`, `~~doorgestreept~~`, links), smileys, a place, a mood ("Gevoel"), up to 2000 characters (`STATUS_MAX_LENGTH`), up to 8 photos (`STATUS_MAX_PHOTOS`; picked from your Foto's box or an open Kudde, or uploaded right there into your Foto's box, several at once as long as they fit; kept in order in `status_photos`, shown as a grid when there are more),  and who can see it (Iedereen or Vrienden). Friends-only posts are hidden from everyone except friends. The composer is your photo with the text field as a speech bubble; the empty field shows one of eleven prompts (`PROMPTS` in `StatusComposer.tsx`), a different one each time.
- **Knuffels:** the profile guestbook.
- **Berichten (`/berichten`):** personal messages with Postvak IN, Verzonden and Concepten. Formatting, smileys and a preview; reply (quotes the original, "Re:") and forward ("Fwd:"); search per folder; select several to delete or mark (un)read. What you type is autosaved as a concept. Opening a message marks it read; Berichten is in your menu under your photo in the header. Sender and recipient each delete their own copy. Privacy: messages from everyone, friends only or nobody; you can always answer someone who wrote to you. Enforced on the server (`server/routes/messages.ts`), with a limit of 40 sent messages per hour.
- **Friends:** send, accept, decline and cancel requests. A bell in the header shows pending requests.
- **Photos:** uploads are re-encoded to WebP with all metadata (EXIF/GPS) stripped. There's a lightbox.
- **Kuddes:** the networks of Kuddes, in categories like Hyves' "Netwerken": Groepen, Spots, Scholen, MBO/HBO/Universiteit, Bedrijven, Stichtingen and Verenigingen (`shared/kuddes.ts`), each with subcategories. Places have an address, city, phone and website. The directory (`/kuddes?categorie=spots`) lists the most popular per category, with a search box and subcategory filter; "Kuddes" in the menu lists the categories. Kuddes are open (anyone can join) or closed (the owner approves requests, and only members see the events). The owner can edit the details.
- **Events and Agenda:** members post events on their Kudde (title, start and end, place, description). Members answer "Ik ga" or "Misschien"; the organiser goes automatically. Every event can be downloaded as an .ics file. `/agenda` shows a month calendar with "Mijn Kuddes" (your Kuddes plus events you're going to) or "Populair" (all open Kuddes), a category filter, the most popular upcoming events and where you're going. Home has an Agenda box.
- **Over Kuddes (`/over-kuddes`):** what Kuddes is, live numbers (members, online, knuffels today, since when), everything you can do with links, what it stands for (free, no ads or tracking, members only, waitlist), who's behind it and credits. Linked from the footer and the Over Kuddes menu. The footer (`src/components/layout/Footer.tsx`) is a card of its own (readable on any theme or background): the name and motto with a link to this page (or "Word gratis lid"), the links as columns with one per line (Ontdekken in two, Jij, Over Kuddes; on an iPad the name goes on top, on a phone everything stacks with the links two by two), and a line with the credits.
- **Suggestions:** public suggestions, plus private problem reports via the floating "Probleem melden!" button. The admin sets where each one stands (Nieuw, Bekeken, Wordt aan gewerkt, Staat gepland, Klaar!, Komt er niet; `shared/suggestions.ts`, `suggestions.status`) with an optional note in Beheer → Meldingen (`PATCH /api/admin/reports/:id`); the sender gets a notification, and the status and note show on /suggesties. Klaar and Komt er niet count as handled.
- **Nieuwe mensen (`/leden`, Ontmoeten):** every member as a tile, newest first, who's online now ("Toon offline" stays hidden) or A to Z, with a search and "Meer leden" (`GET /api/members`); "Bekijk meer" on the homepage's Nieuwste leden goes there.
- **Homepage:** an invite banner, news and updates (written on the admin page), newest members, photos, suggestions, a weather box (Open-Meteo, called from the browser) and Kuddes.
- **Nieuws (`/nieuws`):** the admin writes posts on `/beheer` with the forum's editor (headings, lists, text styles, quotes, links, including `[tekst](/pagina)` to pages on Kuddes, smileys and Kuddes embeds such as videos), plus news-only tools: pictures uploaded into the post (`![onderschrift](/uploads/news/…)`, `POST /admin/news/images`), YouTube links on a line of their own (they load from youtube-nocookie.com only when you press play) and big buttons (`[[Probeer het nu]](/gadgetmarkt)`). A post can have a banner (`news.banner_path`), shown above it, in the news list and in the share image. Members give respect (`news_respects`, `POST`/`DELETE /api/news/:slug/respect`); the post shows how many and who. A post looks like a page from "De Kuddes Courant" (the news box on Home): a dateline, the rubric, a big serif headline with the summary as the lede, the banner under it, and the text in serif with a drop cap, in two columns on wide screens once it's longer than 1200 characters.
- **Sounds:** made with the Web Audio API, no sound files (`src/lib/siteSounds.ts`): a ding-dong for a new personal message, a pling for a friend or relation request, a little tune for an invite to a game or the Graffitimuur, a fanfare for an achievement, and in the chat a quiet blip for others' lines and a brighter one when your name or nickname is mentioned. `useNotificationSounds` (in the layout) watches the queries the header and the game pop-ups already use and plays only for what's new while you're on the site; several at once make one sound. Two switches in Instellingen → Weergave (`notificationSounds`, `chatSounds`), each with "Laat horen". Browsers only allow sound after a first click on the page.
- **Graffitimuur extras:** the wall keeps itself in the browser (IndexedDB `kuddes-spray`, saved a few seconds after each change, for 14 days), so stopping to spray together, going back to `/graffiti` or opening the page again keeps your artwork; "Stoppen" leaves you on the same wall and you can invite someone again from there. While spraying together there's a chat under the wall (over the game room, `__chat` messages in `SprayWall.tsx`), and what a friend says also shows as a speech bubble at their can. "Foto bewaren" puts the picture straight into your Foto's when you're logged in (a WebP, captioned "Gespoten op de Graffitimuur"); logged out it's still a download. Achievement pop-ups have a × and go by themselves after 7 seconds (a bar shows how long).
- **Tools (`/tools`, its own menu in the header):** programs to make things with, in the look of Office 2007: Kuddes Woord, Rekenblad and Presentatie, with all your files on the page, and under them Paint, Planner, Mindmap, Formulieren, Rekenmachine and Kladblok. Files are private (`documents`: `kind` woord/rekenblad/presentatie/studio/paint/mindmap/planner/formulier/kladblok; Woord keeps `html`, the others `content`, checked strictly per kind in `server/routes/documents.ts`), up to 200 per member, in the data download (Woord as web pages, Paint as PNG, Kladblok as text, the others as JSON). Every program opens through `OfficeLoader` and shares the Office chrome in `src/features/office/`.
  - **The shared Office window (`src/features/office/`):** `Office.tsx` has the ribbon's pieces (groups, big and small buttons, menus that float over the page, colour grids), the title bar with the round Office button and the quick access toolbar, the file menu (Nieuw, Openen, Opslaan, Opslaan als, Exporteren, Afdrukken, Verwijderen, recent files), the Openen dialog and the zoom bar; `officeFile.ts` loading and saving a file (`useOfficeLoad`, `useOfficeFile`: autosave every 20 seconds, a new file gets its address on the first save), the colour scheme (Blauw/Zilver/Zwart, one for all three) and Office's palette. Styles and the scheme tokens in `Office.css`.
  - **Kuddes Rekenblad (`/tools/rekenblad`, `src/features/rekenblad/`):** an Excel 2007 grid of A–Z × 200 rows per sheet, up to 10 sheets (tabs at the bottom), name box and formula bar. `formula.ts` reads typed values (12,5 / 1.234,56 / 15% / € 3,50 / WAAR) and formulas as Dutch Excel does (`;` between arguments, Dutch and English names: SOM, GEMIDDELDE, MIN, MAX, AANTAL, AANTAL.ALS, SOM.ALS, ALS, EN, OF, AFRONDEN, TEKST.SAMENVOEGEN, LINKS, VANDAAG…, `$` anchors, `#DEEL/0!` and friends, `#CIRC!` for loops). Copy and paste (also from and to Excel as tabs) move formulas along, the fill handle fills formulas or carries on a number series, sorting keeps a heading and a totals row in place and moves formulas with their row; bold/italic/underline, colours, borders, alignment, number formats (getal, valuta, procent, decimals), AutoSom, column widths, undo. Charts (kolom, staaf, lijn, cirkel) float over the sheet (`Chart.tsx`, SVG). Export to an Excel 2003 XML workbook or CSV (`sheet.ts`), and printing.
  - **Kuddes Presentatie (`/tools/presentatie`, `src/features/presentatie/`):** PowerPoint 2007: slides down the left (drag to reorder), the slide in the middle (960×540, scaled) with notes under it, and a slide sorter. Layouts (Titeldia, Titel en inhoud, Alleen titel, Twee inhoudsvakken, Leeg), text boxes, pictures (from your computer or your Foto's), Hyves smileys and shapes, moved and resized with the mouse (`SlideView.tsx`), fonts, colours, bullets, alignment and order; eight design themes, a background per slide, a transition per slide (vervagen, duwen, wissen, inzoomen, draaien), and the slideshow full screen (arrows, space, click; Esc). Export as a web page that plays by itself, and printing a slide per page (`slides.ts`).
  - **Kuddes Paint (`/tools/paint`, `src/features/paint/`):** Windows 7 Paint: pencil, brush, spray can, eraser (in colour 2), flood fill, colour picker, text, lines and shapes (Shift for squares and 45° lines) with outline and fill, five sizes, colour 1 and 2 (left and right mouse button), the palette and own colours; resize, rotate and mirror, opening a picture from your computer, undo, zoom. Saved as a PNG data URL (up to 2000 px a side); export as PNG, a copy in your Foto's (`POST /photos`) or as your profile picture (`POST /me/avatar`).
  - **Kuddes Mindmap (`/tools/mindmap`, `src/features/mindmap/`):** a root in the middle with its branches split over both sides (`mindmap.ts` lays it out, SVG). Tab adds a subtopic, Enter one next to it, F2 or typing edits, Delete removes, space folds, the arrows walk the map; drag a topic onto another to move it. Branch colours, three styles (klassiek, modern, krijtbord), up to 300 topics. Export as PNG, SVG or an indented text outline.
  - **Kuddes Planner (`/tools/planner`, `src/features/planner/`):** tasks on a board (Te doen, Bezig, Klaar; drag and drop), in a week (drop on a day to plan it) or as a list, with a side panel for notes, date, priority, label and a checklist. Search, label filter, hide what's done. Export as CSV (semicolons, for Dutch Excel).
  - **Kuddes Formulieren (`/tools/formulier`, `src/features/formulier/`):** a form builder (short answer, paragraph, multiple choice, checkboxes, drop-down, number, date, linear scale; required, help text, reorder). The server gives a saved form its own address (`content.publicId`), where other members fill it in once (`/formulieren/:publicId`, `GET /api/forms/:publicId`, `POST /api/forms/:publicId/responses`, stored in `form_responses`, one per member). The maker sees the answers as a summary (bars, averages) or per person, with names unless the form is anonymous, can delete them, and can export them as CSV or open them as a new Rekenblad. Closed forms take no answers.
  - **Kuddes Studio (`/tools/studio`, `src/features/studio/`, `shared/studio.ts`):** making beats and songs in the look of FL Studio with GarageBand 09's metal top and blue display. A channel rack with steps for drums (right-click: a soft hit), a piano roll for instruments, patterns, and a playlist that puts patterns into a song (PAT/SONG). Every sound is synthesized with Web Audio (`engine.ts`: 10 drum sounds, 7 instruments, a look-ahead scheduler, swing, metronome), so there are no samples; Musical Typing (A W S E D…, Z/X for the octave) plays the chosen instrument. Exports the pattern or the song as WAV (rendered offline). Recording, effects, automation, own samples, loops, MIDI and sharing on Kuddes Muziek are shown as coming soon.
  - **Rekenmachine (`/tools/rekenmachine`, `src/features/rekenmachine/`):** the Windows 7 calculator: standard, scientific (degrees or radians, using the Rekenblad's `formula.ts`), graphs (`graph.ts`: its own expression parser, zeros/extremes/intersections, table, slope, area, sliders for parameters) and unit conversion. Memory, history and graphs stay in the browser; no files, so it's open to guests too.
  - **Kladblok (`/tools/kladblok`, `src/features/kladblok/`):** Notepad: plain text with find and replace, time stamp (F5), word wrap, a few fonts, zoom and a status bar; export as .txt.
  - **Kuddes Woord (`/tools/woord`, `/tools/woord/:id`, `src/features/woord/`):** a word processor in the style of Word 2007. The round Office button with the file menu (Nieuw, Openen, Opslaan, Opslaan als, Exporteren to Word .doc, a web page or plain text, Afdrukken, Verwijderen, recent documents), the quick access toolbar, and the ribbon (`Ribbon.tsx`): Start (clipboard, format painter, font, size, colours, highlight, case, lists, indents, alignment, line spacing, the Stijlen gallery, find and replace), Invoegen (page break, table grid, picture from your computer or your Foto's, Hyves smileys, hyperlink, WordArt, horizontal line, date, symbols), Pagina-indeling (margins, orientation, columns, page colour) and Beeld (zoom, page width, ruler, the Office 2007 colour schemes Blauw/Zilver/Zwart, full screen). An A4 page with the printed page ends dotted on it, and a status bar with page, words, save state and a zoom slider. Editing uses the browser's own commands on a contentEditable page (`editor.ts`); everything that goes in or out is cleaned with DOMPurify (pasting from Word too). Documents are private (`documents`, `server/routes/documents.ts`, up to 200 of 6 MB each, pictures inside them as data), saved with Ctrl+S and every 20 seconds, and in the data download as web pages. The window keeps Office's own colours (tokens on `.ofc-app`), not the site theme's.
- **Designgalerij (`/designs`):** members share a site theme or profile design from their library with everyone (`shared_designs`, a copy at that moment without the background photo; at most 20 each; `server/routes/designGallery.ts`). A catalogue page (Alles / Site-thema's / Profieldesigns, search on name, description or maker, sorted by newest, most respect or most used): "Gebruiken" puts it on your profile or the whole site at once, "Bewaren" puts a copy in Mijn designs / Mijn thema's (for a Kudde too), and members give respect (`shared_design_respects`). The sharer edits the name and description or takes it out; the admin can take out any. Sharing from the page or with the palette button on a card in Mijn thema's / Mijn designs (`src/features/designs/ShareDesignDialog.tsx`). Visitors can look; using, keeping and sharing need an account. Included in the data download.
- **Mijn thema's and Mijn designs:** your own site themes, and your own profile/Kudde designs (one library for your profile and all your Kuddes), are cards with a small live preview: use, edit, copy, share as a code (`KUDDES-THEMA:`/`KUDDES-DESIGN:`, a background photo stays yours) or remove; up to 20 of each (`saved_designs`, `GET/POST/PATCH/DELETE /api/me/designs`; PATCH also takes new `data`). "Nieuw" starts blank and always saves as a new one. The editors (`src/features/account/ThemeStudio.tsx`, `DesignStudio.tsx`, helpers in `savedThemes.ts`/`savedDesigns.ts`) have a name, sections, undo/redo (Ctrl+Z/Y), readability checks, the site-wide preview for themes, and a copy in the browser until saved. The own site theme can have a background pattern (`CustomTheme.pattern`, `patternColor`) and a pattern in the top bar (`barPattern`, `barPatternColor`, `--bar-image`); `asLayers` turns a pattern's final plain colour into a flat gradient so it can sit in front of other layers.
- **Unsaved changes:** forms register with `useUnsavedChanges(dirty, { what, save })` (`src/lib/unsavedChanges.ts`); `UnsavedGuard` then asks before leaving (closing the tab, links within Kuddes, switching settings topics via `confirmLeave()`): save and go on, go without saving, or stay. Not the browser's back button.
- **Kuddes Muziek (/muziek):** members with the admin's OK (asked like Kuddes Video's, Beheer → Muziek-rechten) make up to five artist/band pages (`music_pages`, own slug, banner and picture) and upload songs to them (converted to MP3 without the file's metadata, `server/lib/musicProcessing.ts`), with a release year or date and credits (`tracks.credits`, a member's username links to their profile). Genres, a weekly chart with movement (`track_plays`, only when, not who), likes, and a player bar that keeps playing while you browse (`src/features/music/player.ts`, `PlayerBar.tsx`, Media Session). Songs and bands can be shared in Messenger (a shared song plays from the chat) and linked in WieWatWaars. Gadget: Kuddes Muziek.
- **Kuddes Radio (/radio):** members with the admin's OK host live shows from a studio in the browser (`src/features/radio/mixer.ts`: two decks with Kuddes Muziek songs, crossfade and automix, a microphone with push-to-talk and ducking, synthesised and own sound buttons). The mix goes up in 1-second WebM pieces and ffmpeg makes one 96 kbit/s MP3 stream for all listeners (`server/lib/radioLive.ts`); nothing is recorded. Co-DJs connect over WebRTC (STUN/TURN from `/games/ice`), or through the server when that fails. Stations have genres, a programme with playlists, followers (notified when live), chat and reporting; the admin can stop a show. Gadget: Kuddes Radio.
- **Tools gadgets** (category Tools en bestanden, `src/features/gadgets/ToolGadgets.tsx`): Gedeelde bestanden (up to 12 of your files from Tools, each opening read-only on `/profiel/:username/bestanden/:gadgetId/:docId`), one gadget per kind that draws one file in the box (Woord-document, Rekenblad, Presentatie, Tekening, Mindmap, Planner, Formulier with an Invullen button, Kladblok; `DocView.tsx`), and Rekenmachine (a pocket calculator for visitors, or a graph of your functions that links to `/tools/rekenmachine?f=…`). A file is only readable through a gadget that lists it (`GET /gadgets/:id/documents/:docId`, members only); the config may only name your own files of the right kind.
- **Mindfulness gadget:** a breathing circle (three patterns, keeps going until you stop it), a mantra of the day, how the owner feels (set on the profile, with two weeks of moods) and three things they're grateful for.
- **Overzicht** also shows new songs, radio shows that went live and photos put on a photography page (activity types `track`, `radio`, `photography`, tabs Muziek, Radio, Fotografie). **Forum:** who started a topic gets a notification for replies (switch off in Instellingen → Meldingen → Bij de bel).
- **Profielkaartje (`/profielkaartje`):** a public card to put on other sites, off until you switch it on. You choose what's on it (photo, city, age, a bit of "Wie ben ik?", up to 5 favourites, music, gamertags, your own line, and whether it's in your profile's design); your name and a "Word ook lid van Kuddes" button (`/aanmelden?via=<naam>`) are always on it. Only what you chose leaves the members-only part of the site (`shareCardOf` in `server/lib/shareCard.ts`, `users.share_card`, `GET /api/share-card/:username`, `GET`/`PUT /api/me/share-card`).
  - `/kaartje/:username` is the card as a small page of its own, with its own headers so other sites may frame it (`frame-ancestors *`, registered before the site's secure headers); `?embed` for an iframe. It shows the design's background (pattern and photo) as a frame, its title bar, and the name in the design's font, colour and shadow; it also has share meta tags, so a pasted link becomes a picture with text on sites without embeds.
  - The picture version (`/og/kaartje/:username.jpg`, like a business card) draws the same design with sharp: BuddyPoke and SVG patterns are tiled for real, the simple CSS ones are drawn again (`server/lib/patternRaster.ts`), and the rest fall back to the design's two colours. It's also the link preview.
  - The page has a live preview, copy buttons for the link and the embed code, a download, the phone's share menu (with the picture) and links for WhatsApp, Facebook, X and e-mail. Linked from the menu and from the "Kaartje" button in your own profile header.
- **Dark designs:** on a dark site theme (the dark theme, Halloween colours or a dark own theme, `useSiteDark`) light profile designs and Kudde designs are shown dark automatically: their own design, a ready-made one or a built-in skin (`darkDesign`, `designSkin`, `resolveSkinFor` in `shared/skins.ts`), on the profile, its title bar, WieWatWaars on the timeline and in the design editor's preview. Dark designs stay dark on the light theme.
- **Header** (`src/components/layout/Header.tsx`): a floating card a little below the top of the window (on phones it stays in view while you scroll). The logo, the menus and your own buttons on one row; on narrower screens the menus get a light row of their own at the bottom of the card that swipes sideways. Thin lines between the menus and between the buttons; the section you're in looks pressed into the bar. The menus and the colour picker open as speech bubbles with a tail (`bubble` on `Dropdown`), like the bell and your own menu.
- **Search:** members, from the magnifier in the header (or press `/` anywhere): it opens a search field under the bar.
- **Icons:** [Farm-Fresh web icons](https://commons.wikimedia.org/wiki/Farm-Fresh_web_icons) by FatCow Web Hosting, CC BY 3.0 US (credited in the footer). - **Automatiseringen (Beheer → Automatiseringen, `automations` table, `server/lib/automations.ts`, `shared/automations.ts`, `src/features/automations/`):** "als dit, en dit klopt, dan dat". Triggers: a member comes online again (after N minutes away; from the session middleware), logs in, someone wants to sign up (checked before the account exists, so it can be refused with the same plain answer as the blacklist), a new account, a new member let in, posting something visible (via `checkPost`), a friend request, every day at a time (for the named members, or once). Conditions: only these members, a word from a list (in the name/username/e-mail at sign-up, the text when posting, else the name), away at least N days, account age, once per member. Actions (in order): refuse the sign-up, a message (from a bot or the admin), a knuffel or WieWatWaar from a bot, a melding, block, log out, IP ban (the last address), blacklist, give or take video/music/radio rights, approve. The admin actions live in `server/lib/memberActions.ts`, shared with Beheer. Every action is in the Logboek (as "server"); the admin is never blocked, logged out, banned or blacklisted; bots don't set automations off. "Proberen" is a dry run on a member that also says why it wouldn't apply.
- **Bots (Beheer → Bots, `bots` table, `users.is_bot`, `server/lib/bots.ts`, `shared/bots.ts`, `src/features/bots/`):** accounts that act by themselves, always shown with a "Bot" label (`BotBadge`, from `UserSummary.bot`). A task bot has rules (Nieuw lid / Verjaardag at 9:00 / Bericht ontvangen / Knuffel ontvangen / Elke dag at a time → knuffel, bericht or WieWatWaar, with `{voornaam}`, `{naam}`, `{gebruikersnaam}`). An AI bot asks LM Studio (its OpenAI-compatible `/v1/chat/completions`, address in site setting `lmStudio`) with its instructions and abilities as tools (bericht_sturen, knuffel_geven, wiewatwaar_plaatsen, lid_bekijken, nieuws_lezen); its plain answer goes back where the trigger says. Events come from `welcomeMember` (new members), sending a message to a bot, and knuffels on a bot's profile; a clock every 30 s runs the daily ones (`state` keeps what ran today). Each bot also has behaviour options (`bots.options`): accept friend requests automatically (also waiting ones, on save), mark messages to it as read, open its own privacy settings to everyone, wait a while before reacting, and its own limit per hour; task bots can also send friend requests (to new members, say), and AI bots have that as an ability. A bot can also keep watch (Toezicht, `bots.moderation`, `server/lib/moderation.ts`, word matching in `shared/moderationWords.ts`): what members post where others see it (WieWatWaars, knuffels, reacties, forum, Kuddes, photo and video comments, blogs; never private messages) is checked against the admin's word list (with * and common disguises) and behaviours (flooding, copy-paste, links, shouting, many friend requests); it then warns (a message from the bot), can remove the post (WieWatWaars, knuffels, reacties) and can add a melding in Beheer → Meldingen, also once a member reaches a number of warnings in 30 days. Warnings are `bot_warnings`, kept a year, in the data download, and can be withdrawn in Beheer. Only the first bot with Toezicht on keeps watch; the admin and bots are skipped. Bots never react to bots, do at most 60 things an hour, respect who may knuffel or message a member, and run one at a time. "Proberen" in Beheer is a dry run. The admin can log in as a bot.
- **IP bans (Beheer → Zwarte lijst, `ip_bans` table, `server/lib/ipBans.ts`, `shared/ipBans.ts`):** a connection banned for 1, 7 or 30 days or for always, from signing up and logging in (`/auth/register`, `/auth/login`) or from the whole site (a middleware in `server/index.ts`). A banned visitor only gets what looks like an ordinary error (500, "Er ging iets mis", `GENERIC_ERROR`), so they can't tell they're banned. An IPv6 address covers its /64; ranges go from /16 (IPv4) or /32 (IPv6), and a ban never covers the admin's own connection, and the admin's session and login are never blocked. Members' last address is `users.last_ip` (set by the session middleware, erased 90 days after the last visit by the session purge, in the data download); "IP bannen" in Leden bans it.
- **Beheer (`/beheer`, admin only):** tabs in the catalogue bar (big icons, swiping on a phone, waiting numbers on Aanmeldingen/Meldingen/Video-rechten); Leden sorts on the server (newest, oldest, last online, name, most WieWatWaars/photos/videos/forum posts) and shows as a list or a grid of cards; overview numbers, news (drafts and scheduled posts, stored in the `news` table), members (search, block with a reason, which logs them out at once; temporary password; delete with everything they posted), dummy accounts with "Inloggen als", every upload with delete, content moderation across WieWatWaars, knuffels, reactions, forum and kuddes, problem reports, forum stickies and locks, and a log of every admin action (`admin_log`). Code: `server/routes/admin.ts`, `src/pages/AdminPage.tsx`.
- **Kuddes Forum (`/forum`):** a message board in its own 2009 style, on the same Kuddes accounts. Sections grouped in categories (admins manage them; "team" sections only take threads from staff), threads with up to 5 tags, readable URLs and pages of 20 posts, pinned/locked/hot icons, search and tag pages. Posts use the Kuddes markup plus `> ` quotes (Citeren fills them in), a preview tab, smiley reactions (Hyves smileys, one of each per member), and **Kuddes embeds**: a link to a video, profile, Kudde, event, forum topic or forum profile on a line of its own becomes a card (videos play right there). Every member has a **forum profile** (`/forum/lid/:username`) with a title, signature, stats, recent posts and topics, and a Discussie wall. **Roles:** the site admin (hein, see above) can do everything on `/forum/beheer`: sections, section moderators, bans (for a number of days or for good) and chat channels. Moderators pin, lock, move, edit and remove in their sections. Removed posts keep their place. **Chat (`/forum/chat`):** IRC-style live channels over Server-Sent Events (`server/routes/chat.ts`), with history, a user list (@ admin, % moderator), `/me`, `/topic` and `/kick` (5 minutes) for moderators, `/join`, `/clear`, `/help`, Tab to complete names and ↑ for earlier lines; flood protection and bans apply. Chat connections live in the API process, so it needs a single server (or a shared pub/sub to scale out).
- **Kuddes Video (`/video`):** members' own videos, in the style of 2009 YouTube: a home page (recommended, being watched now, best rated, most viewed, newest), search and browsing by category or tag, a watch page with 1–5 star ratings, favourites, comments, sharing, the uploader's info and related videos, channels per member (uploads and favourites), and an upload page with drag & drop and a progress bar. Videos are openbaar, verborgen (link only) or friends-only. Uploading needs the admin's permission: new members ask on the upload page (reasons, a note, agreeing to the rules), the admin gets a personal message and answers on `/beheer` (`video_upload_requests`, `users.video_upload_allowed`). Uploads (MP4/MOV/WebM/MKV/AVI up to 100 MB, cut at 15 minutes) are streamed to disk and compressed by **ffmpeg** (with libx265, needed on the server) to H.265/HEVC + AAC MP4 at most 1280×720 and 30 fps (CRF 30, tagged `hvc1` for Safari), with metadata stripped and a WebP thumbnail. Older videos stay H.264 (`videos.codec`); the player explains when a browser can't play HEVC; one at a time, resumed after a restart (`server/lib/videoProcessing.ts`). Playback streams through `/api/videos/:id/file` with Range support, so friends-only videos stay private. The custom player (`src/features/video/VideoPlayer.tsx`) has the site's glossy look: seek bar with buffering, volume, fullscreen and keyboard shortcuts (space/k, ←/→, ↑/↓, m, f). Related videos are ranked by shared tags, category and uploader; recommendations use the tags of what you rated highly, favourited or commented on. New videos appear on the timeline, and the "Kuddes Video" gadget puts your latest or chosen videos on your profile.
- **Gadgets:** besides BuddyPoke, members can add Plaknotities (paper notes pinned to a cork board, edited right on the profile), Muziek (a glossy MP3 player with an LCD and a YouTube playlist), Video (YouTube videos), Aftellen (flip-card countdown), Poll (one vote per member, can be changed or closed), Boekenkast, Filmrek, Platenkast and Spellenkast (drawn covers, dvd's, cd's and records, and game boxes per platform on shelves; the owner picks the furniture, from a wooden bookshop case or a mahogany one to a video store, a cinema, a tv cabinet, a game store or the cd wallet from the car) and Recepten (your own recipes and the ones you found lekker). Nobody has any by default (max 48). Each gadget is its own box in the profile layout (slot `gadget:<id>`), so it can be moved and hidden. YouTube links are reduced to video ids on both sides; titles are looked up via YouTube's oEmbed, and the player only loads (from youtube-nocookie.com) when you press play, unless the owner set the music to start by itself. Visitors can turn that off (Instellingen → Weergave); when the browser blocks it (or starts it muted), a button asks for a click. The page talks to the embed over postMessage (`enablejsapi`), without YouTube's API script. Code: `shared/gadgets.ts`, `server/routes/gadgets.ts`, `src/features/gadgets/`.
- **Huisdier, forum, plakboek and scores:** Virtueel huisdier (a drawn kat, hond, konijn or draakje in a colour of your choice, `PetArt.tsx`; eten, aandacht and plezier run empty in 24, 18 and 30 hours; every member, the owner too, can feed, pet or play once per 3 hours per action, `POST /gadgets/:id/huisdier`; between 23:00 and 7:00 Dutch time it sleeps; it grows from baby to jong to volwassen with care; every bit of care earns the owner coins, 2 from a visitor and 1 from yourself, to spend in the pet's shop on backgrounds (tuin, strand, snoepland, ruimte, kasteel) and hats (strik to kroon), `POST /gadgets/:id/huisdier/winkel`, `PET_BACKGROUNDS`/`PET_HATS`; `gadget_pets`, `pet_care`), Forumberichten (your latest posts, as plain text, with a link to the post, or the threads you started, plus your forum title and counts), Glitterplakboek (your collection, your uploads or picked ones, taped into a spiral scrapbook of six per page, on pink, blue, kraft, squared or black paper; visitors can collect one from it) and Spelscores (won, drawn and lost overall and per game, the win percentage, streaks, the last five games and your rival: whoever you played most one on one, at least 3 times; the Graffitimuur doesn't count). What they show is loaded in `server/lib/gadgetExtras.ts`.
- **Spelscores look:** the numbers are tiles in Oswald (SIL Open Font License, self-hosted in `public/fonts/oswald-600-latin.woff2`, because the CSP only allows fonts from the site); the Scorebord style makes them lit-up flip tiles on a dark board.
- **Gadgetmarkt (`/gadgetmarkt`):** every gadget type as a card in a shop window, with a category list (`GADGET_CATEGORIES`; each type in `GADGET_TYPES` names its category), search (name, description and category, accents ignored; in the URL as `?q=`), sorting by popularity (members showing one, `GET /gadgets/populair`) or A–Z, and a meter of the 48 places used. Adding one opens its settings right away. The tab **Mijn gadgets** (`?tab=mijn`, `#gadget-<id>` opens one) is where you show, hide, change and remove them, BuddyPoke included. On the profile, Indeling → Gadget toevoegen opens the same catalogue as a search list (typing filters, ↑/↓ and Enter add). A new gadget type needs no changes here: it appears in both by itself. Instellingen only links to it now. Code: `src/pages/GadgetMarketPage.tsx`, `src/features/gadgets/GadgetMarket.tsx`, `gadgetCatalog.ts`.
- **Eigen thema and eigen design:** besides the built-in themes, members can make their own site theme (colours, light or dark boxes) and their own profile design (two colours, a pattern, box/title/link colours). Both can have an uploaded background image (tiled, filling, fitting, stretched or centred, optionally fixed while scrolling; animated GIFs stay animated) and see-through, blurred boxes. Background uploads are stored as `/uploads/backgrounds/<userId>-….webp` and members can only use their own. The colour maths is in `shared/customization.ts`; `index.html` restores the theme before the first paint.
- **Indeling:** the boxes on your profile ("Over" tab, three columns) and on Home (three columns, like the old Hyves start page: Jij, Wie is er nu? (online friends) and Jarige vrienden on the left, WieWatWaar, one box with the tabs Foto's, Video's and Blogs (like on Hyves; `MediaTabsBox`) and Nieuw op Kuddes in the middle, De Kuddes Courant, Smileys in de laatste 24 uur, Agenda, Kuddes, Ideeënbus and Het weer bij jou on the right) can be dragged, moved with arrow buttons or hidden, via "Indeling" on your profile or "Home aanpassen". Stored layouts are normalised (unknown boxes dropped, new boxes added in their default column; a layout saved with another number of columns starts again from the default, keeping what was hidden). Home has member-only boxes: Jij (your photo, menu and profile progress), Wie is er nu? and Jarige vrienden. Visitors get a welcome with a login box (`src/features/home/VisitorWelcome.tsx`) and the news wide.
- **Mijn indelingen:** save your current look (theme, profile design and both layouts) under a name, up to 12, and switch between them in Instellingen or from the palette menu.
- **Preferences:** text size, compact mode, less motion, exact timestamps, the page to open after logging in, the default visibility of WieWatWaars and Ctrl+Enter to send. Privacy: knuffels from friends only, hiding your age, and visiting profiles anonymously (all enforced on the server). Account: log out on all other devices, and download your data: a zip (`GET /api/me/export`, streamed by `server/lib/zipStream.ts` with fflate) with everything you placed as `gegevens.json`, every upload it points to under `uploads/` (photos, videos, music, Kudde pictures, glitters, backgrounds...) and a LEESMIJ.txt.
- **BuddyPoke:** the full BuddyPoke app (the HTML5 port in `web/`, a separate repo) runs in host mode (`web/index.html?host=kuddes`) on your own profile's BuddyPoke tab. Friends are your Kuddes friends with their own buddies and moods; pokes go to real members and are stored in `buddy_events`; your appearance, mood and gold are saved on your account (`web/js/hostsocial.js` talks to `/api/buddypoke/*`). Profiles show the member's buddy (`web/gadget.html`), who poked them (click a poke to play it once in that small buddy, with the poker's buddy: the page posts `{source: 'kuddes', type: 'poke'}` to `gadget.html`, which answers `poke-start`/`poke-end`; see `web/js/gadget.js`), and a "Poke!" button that opens the app with that member picked. The API serves only the app's files from `web/` at `/buddypoke/`.
